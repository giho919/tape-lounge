이곳에 대하여

Tape Lounge는 암호화폐 시장의 가격, 추세 후보, 공개 리포트를 연결하는 독립적인 관찰 공간입니다. 거래소가 아니며 이 웹사이트에서 실제 주문을 집행하지 않습니다. 가상의 인기 순위나 방문자 수를 만들지 않습니다.

출처와 방법

가격: Binance 공개 현물 API. 원화: Upbit 공개 API. 환율: Frankfurter 일일 기준환율. 레이더: 당시 게시된 Andy 리포트. 원문과 관측 시각을 함께 확인하세요. API 장애나 거래소별 종목 불일치 시 해당 값을 비워둡니다.

공개 관찰 JSON과 RSS를 제공합니다. JSON의 reportAt이 관찰 시각이며 웹페이지 생성 시각이 아닙니다. 과거 최초 관측은 보관 범위 안에서의 최초이며 전체 시장의 최초 신호가 아닙니다. 백테스트와 실제 매매 성과를 합치지 않습니다.

개인정보와 언어

기존 익명 방문 통계를 사용합니다. 무작위 브라우저 ID, 화면 종류, 실제 활동 시간, 유입 도메인만 기록하며 IP·기기 지문·검색어를 수집하지 않습니다. 내부 방문 표시는 유지됩니다. 원본 세션은 14일 뒤 일별 집계만 남깁니다.

첫 방문의 언어 추천에 country.is 국가 조회를 사용합니다. 이 제공자는 요청 IP를 보게 됩니다. Tape Lounge는 IP나 위치를 저장하지 않습니다. 조회 실패 시 브라우저 언어를 사용하며, 선택한 언어가 우선입니다.
