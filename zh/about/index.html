关于这里

Tape Lounge 是连接加密市场报价、趋势候选和公开报告的独立观察空间，并非交易所，也不会通过此网站执行真实订单。我们不虚构人气排行或访问人数。

来源与方法

价格来自 Binance 公开现货 API，韩元报价来自 Upbit，汇率来自 Frankfurter 每日参考数据，雷达来自当时发布的 Andy 报告。请核对来源与观测时间。接口不可用或交易对不匹配时留空。

提供公开观察 JSON 与 RSS。reportAt 是观察时间，不是网页构建时间。首次观察仅指保留存档内的首次，不是全市场首次信号。不会将回测与实盘业绩合并。

隐私与语言

首次访问的语言推荐使用 country.is，该服务会接收到请求 IP。Tape Lounge 不保存 IP 或位置。查询失败时使用浏览器语言；您的主动选择始终优先。
